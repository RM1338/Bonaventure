Bonaventure — teammate setup (Linux, NVIDIA GPU >= 6 GB, Python 3.12+)

1. Extract each model file you received in your HOME folder (paths matter):
     cd ~ && for f in medgemma.tar clear.tar medsam.tar chexzero.tar; do [ -f "$f" ] && tar xf "$f"; done
   medgemma -> ~/bonaventure/models/medgemma-1.5-4b-it   clear -> ~/bonaventure/models/clear + ~/Bonaventure/CLEAR
   medsam -> ~/Bonaventure/MedSAM   chexzero -> ~/Bonaventure/CheXzero   (clone the app code FIRST: git clone https://github.com/RM1338/Bonaventure.git ~/Bonaventure)

2. System packages (Arch):  sudo pacman -S webkit2gtk-4.1 python-gobject pango
   (Ubuntu: sudo apt install libwebkit2gtk-4.1-0 gir1.2-webkit2-4.1 python3-gi libpango-1.0-0)

3. Python env:
     cd ~/Bonaventure
     python -m venv --system-site-packages .venv
     .venv/bin/pip install torch==2.11.0 torchvision==0.26.0 --index-url https://download.pytorch.org/whl/cu128
     .venv/bin/pip install -r requirements.txt

4. Run:  ./run.sh          (no GPU / UI only:  BV_MOCK=1 ./run.sh)
